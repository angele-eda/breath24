# Breathe24

Breathe24 is a React/Vite breathing timer with guided Korean voice cues, sound cues, session history, settings, and light/dark modes.

## Breathing Patterns

- 4-2-6 안정 호흡
- 4-7-8 수면 호흡
- 박스 호흡
- 4-4-6 이완 호흡
- 5-5 코히런트 호흡
- 복식 호흡
- 교대 비공 호흡
- 사용자 맞춤 호흡

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

GitHub Pages deployment is configured in `.github/workflows/pages.yml`. The custom domain is preserved through `public/CNAME`.
